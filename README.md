# Naval Dhandha — Personal Portfolio

Responsive, accessible, one-page portfolio website using plain HTML, CSS, and JavaScript. No build system is required.

## Preview locally

Open `index.html` in your browser, or from this folder run:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Publish with GitHub Pages

1. Create a public GitHub repository named `NavalDhandha.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and `resume.docx` to the repository root.
3. In GitHub **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Visit `https://NavalDhandha.github.io/` after GitHub Pages builds the site.

## Customize

- Update text, projects, links, and metrics in `index.html`.
- Change color tokens and typography in `styles.css`.
- Adjust project filters and theme behavior in `script.js`.
- Replace `resume.docx` with your latest resume and check the email addresses before publishing.

## Notes

- Work history and impact figures were adapted from the existing Resume_Naval_Dhandha.docx.
- Project descriptions and repositories were adapted from the public GitHub profile at github.com/NavalDhandha.
- LinkedIn profile details could not be retrieved directly (LinkedIn access restriction); the profile URL is linked.
- No analytics trackers, third-party widgets, or backend services are included. Google Fonts are loaded from Google servers; for fully offline use, switch to system fonts.
